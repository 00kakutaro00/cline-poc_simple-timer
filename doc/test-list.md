# Simple Timer GUIテスト項目リスト

1.  **初期状態のテスト:**
    *   タイマーが`01:00`と表示されていること。
    *   円錐グラデーションが0度の状態であること。
    *   針が0度の位置にあること。
    *   開始/停止ボタンが「再生」アイコンで表示されていること。

2.  **開始/停止機能のテスト:**
    *   開始ボタンをクリックすると、タイマーが60秒からカウントダウンを開始すること。
    *   停止ボタンをクリックすると、タイマーが一時停止すること。
    *   開始/停止ボタンのアイコンが、再生/一時停止で切り替わること。

3.  **リセット機能のテスト:**
    *   リセットボタンをクリックすると、タイマーが初期状態（`01:00`）に戻ること。

4.  **時間表示のテスト:**
    *   タイマーが`MM:SS`形式で表示されること。
    *   時間が正しく60秒からカウントダウンされること。

5.  **円錐グラデーションのテスト:**
    *   タイマーの進行に合わせて、円錐グラデーションが変化すること。
    *   60秒から0秒まで、円錐グラデーションが正しく変化すること。

6.  **針の回転のテスト:**
    *   タイマーの進行に合わせて、針が回転すること。
    *   60秒から0秒まで、針が正しく回転すること。

7.  **タイムアップ時のテスト:**
    *   タイマーが0になったときに、タイマーが停止し、初期状態に戻ること。

8.  **CSSスタイルのテスト:**
    *   タイマーのスタイルが、`style.css`で定義されたスタイルと一致すること。

9.  **JavaScriptの動作のテスト:**
    *   JavaScriptが正しく動作し、タイマーのロジックが正常に機能すること。

10. **ボタンの表示と動作のテスト:**
    *   ボタンが正しく表示されること。
    *   ボタンをクリックしたときに、対応する機能が実行されること。
