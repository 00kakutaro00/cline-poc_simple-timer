# Simple Timer 仕様書

## 1. プロジェクト概要

Simple Timerは、60秒から0秒までカウントダウンするタイマーで、円錐グラデーションと針を使用して、視覚的に時間を表示します。

## 2. 機能要件

*   **開始/停止機能:** タイマーを開始/停止できます。
*   **リセット機能:** タイマーを初期状態に戻すことができます。
*   **時間表示:** タイマーの残り時間を`MM:SS`形式で表示します。
*   **視覚的表現:** 円錐グラデーションと針を使用して、残り時間を視覚的に表示します。

## 3. 入力

*   なし

## 4. 出力

*   タイマーの残り時間（`MM:SS`形式）
*   円錐グラデーションと針による視覚的な時間表示

## 5. 依存関係

*   Tailwind CSS: スタイル
*   Font Awesome: アイコン

## 6. 詳細設計

### 6.1. HTML構造 (`index.html`)

*   タイマーの表示 (`#timer`)
*   開始/停止ボタン (`#play`)
*   リセットボタン (`#reset`)
*   円錐グラデーション (`#conic`)
*   針 (`.hand`)

### 6.2. JavaScriptロジック (`script.js`)

*   タイマーの開始/停止 (`playBtn.addEventListener`)
*   タイマーのリセット (`resetBtn.addEventListener`)
*   時間のフォーマット (`formatTime`)
*   円錐グラデーションの角度計算 (`calcDeg`)
*   タイマーの実行 (`run`)

### 6.3. CSSスタイル (`style.css`)

*   円錐グラデーションのスタイル (`.bg-conic`)
*   針のスタイル (`.hand`)
